# Amit Arya — New Portfolio

Modern interactive portfolio built with:

- **Vite + React + TypeScript**
- **Tailwind CSS v4**
- **Framer Motion** (entrance + scroll reveals + hover)

## Run locally

```bash
cd new-profile
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Design notes

Ink background with **lime** and **coral** accents, Syne + Manrope typography, full-bleed hero with brand-first composition, and scroll-triggered motion throughout.
